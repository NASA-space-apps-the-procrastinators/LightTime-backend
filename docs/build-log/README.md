# Build log

These are the working notes from the hackathon weekend, 14 and 15 November 2026: the step-by-step build plans, the reviews of the code and the data, and the task lists handed to the console owner. Most were drafted with AI assistants (Claude and Claude Code) and checked by the team; every use is logged in [AI_USE.md](../../AI_USE.md).

They are kept for transparency, so anyone can see how the backend was planned and checked. Nothing in the code reads them. Some plans contain code that was copied into the codebase at the time; where the two differ, the code and its tests are right.
